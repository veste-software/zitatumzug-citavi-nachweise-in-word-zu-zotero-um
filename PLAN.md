Verify: scan test on every fixture equals `expected.json`.
- [x] **CSL mapping (basic types).** `src/core/csl.ts`: Citavi `Reference` → CSL-JSON for Book, BookEdited, JournalArticle, Contribution (chapter via `ParentReference`: `container-title`, `editor`, `publisher`), Thesis, InternetDocument, fallback `document`; persons → `family`/`given`, organisations → `literal`; stable `id` per Citavi `Reference.Id`; `PageRange` → `locator` + `label: "page"` (handle the plain-string and structured shapes; unknown shape → keep the raw text as locator); `Prefix`/`Suffix`. Handle inline (inside `w:p`) and block SDTs (wrap in a `w:p`). CSL JSON per SPEC §5.4 (random `citationID`, `noteIndex`, no `formattedCitation`, schema URL). Store in `localStorage` key `zitatumzug-pass`, show it as a copyable code with a field to paste it on another device. Verify: SPEC §6 criterion 11 (valid, expired, tampered, wrong key).
- [x] **Checkout function.** `functions/api/checkout.ts` + `functions/_lib/stripe.ts`: POST creates a Stripe Checkout Session via REST (`fetch` injected) for `STRIPE_PRICE_ID`, `success_url` = `${SITE_URL}/?session_id={CHECKOUT_SESSION_ID}`; 503 when `STRIPE_SECRET_KEY` is unset; no cookies. Verify: SPEC §6 criterion 12 with a mocked fetch.
- [x] **Verify function.** `functions/api/verify.ts`: GET `?session_id=` retrieves the session, if `payment_status === 'paid'` returns a token signed with `UNLOCK_SIGNING_KEY` (30-day expiry), else 402. Verify: tests for paid / unpaid / unknown.
- [x] **Paywall UI.** Under the scan summary and test-copy button: price tag „Umzugspass – 9 € einmalig, 30 Tage“, what is free / what is included, a required checkbox for consent to immediate delivery and loss of withdrawal right (§ 356 Abs. 5 BGB) with link to Kaufbedingungen, button „Alle N Nachweise umwandeln – 9 € einmalig“. On 503/network error show notice „Bezahlung ist gerade nicht verfügbar“. On return with `session_id` call verify, store the token, enable full download `<name>_zotero.docx`. Verify: build; a unit test of the small state helper (no token → paywall, valid token → full button).
- [x] **Anonymous event counter.** `functions/api/event.ts` accepts only `{ "e": "scan_done" | "test_download" | "checkout_start" | "full_download" }`, rejects anything else (400), stores nothing but the name (Analytics Engine/KV binding from `EVENTS_BINDING`; no-op when unbound), sets no cookies. `src/lib/track.ts` sends it with `fetch(href('/api/event'), { method: 'POST', keepalive: true })` and swallows errors. Verify: function test + test that the payload is only the event name.
